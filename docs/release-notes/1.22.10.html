SwiftBot 1.22.10

A focused Announcer audio fix: speech that came out stretched and distorted, and a class of synthesizer whose output merged as pure silence.

Speech That Sounds Like Speech

- A synthesizer that changes its output format partway through an utterance is no longer merged as though it had not. The merge kept only the first chunk’s format, so the whole render was resampled at the wrong ratio and played back stretched, pitched, and distorted. Mismatched chunks are now reconciled to the established format before they are collected.
- The synthesizer’s output format is logged once per render, and any mid-render change is logged loudly, so a recurrence is provable rather than inferred.

Two Further Defects in the Same Merge

- The merge indexed by the destination buffer’s layout without checking that a chunk matched it or that it fit, so a differing channel count could write past the allocation.
- An Int16 synthesizer matched no copy path at all — float-to-float and int16-to-float existed, int16-to-int16 did not — so its render merged as silence.

Release Details

- Updated MARKETING_VERSION to 1.22.10 and CURRENT_PROJECT_VERSION to 2026082110.
- Added regression coverage for the merge, including a mid-render sample-rate change; the suite is 387 tests.
