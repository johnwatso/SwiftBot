Add Rewind message archive and prepare SwiftBot 1.26.1

Rewind archives guild message text so an arbitrary word or phrase can be
counted retroactively, and rolls the same traffic into per-day counters for
leaderboards and a year-in-review.

Storage is append-only JSONL month shards plus per-day aggregate JSON under
`rewind/<guildID>/`. Deliberately not part of AnalyticsRuntimeStore, which
re-encodes its whole file on every append — fine at command volume, ruinous at
message volume. Files are written 0600 inside 0700 directories, and `start()`
narrows an archive created before that was true; the archive is also excluded
from Time Machine by default, since a backup target is usually less protected
than the machine holding it.

Ingest hangs off handleMessageCreate above the bot guard and above that
handler's early returns, so the include-bots setting can see bot traffic and a
watched music link cannot silently drop a message. Timestamps come from the
snowflake so live ingest and the REST backfill derive dates identically.

`/rewind query:<phrase>` counts occurrences over the whole archive. Matching
runs on the token stream rather than raw substrings, so "how often is" matches
"How often IS this?" while "is" never matches inside "island".

Collection ships off. The admin web mirror is read-only and admin-gated: its
top words and phrases are verbatim fragments of members' messages, not
operational metrics like the analytics feed beside it.

Also drives the dashboard sidebar from a declared layout instead of hand-written
rows, with a test that every SidebarItem is reachable — Rewind first shipped
with an enum case and a detail view but no row, which compiled and rendered in
the web UI while being unreachable in the app.
