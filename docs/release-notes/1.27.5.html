SwiftBot 1.27.5

Version 1.27.5 · Build 2026112712

Game Tracker: finals.id club support. A personal finals.id key can no longer read other players' profiles, so tracked teammates showed as “Rank hidden”. SwiftBot now reads their SR from the roster of the club your finals.id account is in, which a personal key can still see.

Club sync. A new Sync finals.id club switch in Game Tracker › Automation adds every named club member as a tracked player before each check, posting to the channel you choose. Members finals.id only knows from the top-10,000 leaderboard can be included or left out. Opted-out “Anonymous” members are never added.

Synced players who leave the club are paused, then resumed if they come back. Players you added yourself are never paused. Deleting a synced player stops the sync adding them again. A failed or empty roster read changes nothing.

Each new player's first check records their current SR without posting. Rank-change announcements start from the next check. Play-session stats (kills, deaths, damage) still need the player's own finals.id data, which a personal key can't read for other players.

Fixes. Release builds compile again: Lookup's autocomplete reply no longer trips Swift's strict concurrency check.

Includes the unreleased 1.27.4 changes.
