SwiftBot 1.27.1

Version 1.27.1 · Build 2026100415

A clearer web overview, easier passkey management, and improvements to Game Tracker, Sweep, and Rewind.

Web admin

  • The Overview refreshes automatically and uses plain-language bot status, grouped voice sessions, and one filterable activity feed.
  • This week highlights active features, meaningful changes, and issues. Zero-value stats stay hidden, and busier features can take their place.
  • Manage passkeys in a compact Preferences dialog. A quieter Use a passkey link keeps Discord as the main sign-in action.
  • Added web controls for bot start, stop, restart, permissions checks, software updates, and Announcer testing and reconnection.
  • Welcome Flow and Sweep gain test controls. Patchy test sends report their result directly.

Game Tracker and Sweep

  • Customise Game Tracker announcement style, shared stats, and text, with a preview of the Discord post.
  • Game Tracker supports leaderboard position and records finished play sessions for analytics.
  • Sweep suggestions focus on substantial cleanup, show one recommendation per channel, and remember dismissed suggestions for 30 days.
  • Sweep previews group actions by reason, with counts and examples.

Rewind, security, and reliability

  • Rewind recap DMs can target active members. The new default requires recent conversation activity as well as participation in the recap period.
  • Optional admin passkeys are linked to Discord access and stored securely for this Mac and web address.
  • SwiftMiner pairing credentials move to the macOS Keychain; protected SwiftMesh credential sharing helps a backup Mac take over.
  • Patchy diagnostics appear in the main Activity log.
  • Automatic updates can finish installation and relaunch through the web controls.

New weekly feature counters begin collecting after this update.
