SwiftBot 1.27.0

The web admin is now a full home for SwiftBot, and server members can
sign in to see their own Replay and clips.

Members
- Server members can sign in with Discord (off by default) to a home
screen of apps: their own Replay and the clips they're in.
- Members only ever see their own data: every admin page is closed to
them, and every video they play is checked against the clips they're in.

Clips and Recordings
- SwiftBot works out who was in each clip from voice history and the
folder's "Recorded by" member. Filter Recordings by person, and see who
is in each clip and which game it's from.
- A redesigned Recordings page with game artwork, a Plex-style game page
and a cleaner player.
- Smoother playback: a lighter copy is prepared for newer clips, and
hidden previews stop streaming. This fixes audio cutting out and video
freezing while audio carried on.
- The clip editor and exports are retired for now.

Operators
- Each Mac and SwiftMesh node can have an operator, who gets a Discord DM
when Discord disconnects, a Mac goes offline, a recordings folder can't
be reached, errors pile up, or a node's role changes. Each alert can be
switched off, and there's a test alert.
- About this server shows each Mac's model.

Rewind and Replay
- Members can be DM'd their personal Replay, with an opt-out from the DMs.
The Rewind opt-out is gone.
- Rewind can fill gaps in its archive automatically each night.

Apple Intelligence
- Apple Intelligence settings have moved into Settings, with three
personalities plus a custom one.
- The bot can answer activity questions like "what time does Sam usually
jump on?" from real voice history.
- Requests use Private Cloud Compute where available and fall back to the
on-device model.

Web admin
- New pages: Community analytics, the Activity feed, Access, Game Tracker
editing, and SwiftMesh, including the handover test and node actions.
- Sweep now covers voice-channel chats and webhook posts. A review step
runs before a rule is saved, and new rules can start from templates.
- The Overview's health status is the same in the app and on the web.
- A redesigned sign-in screen, Preferences page (with light and dark
wallpapers) and SwiftMesh page.

Native app
- A calmer sidebar, with grouped sections and clearer status.
- SwiftBot builds with Xcode 26 (Swift 6.2) as well as Xcode 27. Xcode 26 builds use
the on-device Apple Intelligence model.
