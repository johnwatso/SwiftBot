Prepare SwiftBot 1.26.2

Renders SwiftMiner's new friend invitations. A SwiftMiner operator can now
pick someone from the connected Discord server and have SwiftBot deliver
an invitation to connect their own Twitch account.

This is the one DM whose recipient may never have heard of SwiftMiner, so
it leads with what SwiftMiner is, carries the invitation link as its
primary button and an explainer as a secondary one, and says plainly that
signing in happens on Twitch and shares no credentials with the inviter.
No activation code or Twitch activation URL appears in the message.

It also never falls back to advertising the operator's dashboard, which
the recipient cannot sign in to, and the per-type notification
preferences do not gate it: those describe ongoing alerts for an existing
miner, and none of them should silence a one-off invitation sent by hand.
