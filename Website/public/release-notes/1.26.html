SwiftBot 1.26

Version 1.26 · Build 2026090216

This release restores real Discord profile pictures for linked SwiftMiner accounts immediately after SwiftBot starts.

SwiftMiner Integration

  • SwiftBot now resolves the current Discord identity for every linked SwiftMiner user instead of waiting for a new gateway event before it knows the member's avatar.
  • Identity lookups are limited to linked users, run concurrently, and retry after temporary Discord API failures.
  • Existing server display names remain intact while usernames and custom avatar URLs are refreshed.
